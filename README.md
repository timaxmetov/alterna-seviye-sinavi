# Alterna Seviye Sinavi

Экзамен на уровень турецкого языка в формате TOMER для русскоязычных. Одна страница, без бэкенда: всё считается в браузере, результаты хранятся локально у сдающего.

Сайт: https://timaxmetov.github.io/alterna-seviye-sinavi/

Телеграм канал проекта: https://t.me/alterna_turkish

## Что внутри

Шесть режимов: виртуальный экзамен TOMER на 47 заданий и 45 минут, адаптивный тест, экзамен по одной секции, тренажёр с мгновенной проверкой, работа над ошибками, тест словарного запаса. Плюс тренировка по отдельному юниту учебника.

Пять секций: грамматика, лексика и идиомы, чтение, аудирование, письмо и построение фраз.

Банк из 1033 заданий A1 - C1. Задания и порядок вариантов перемешиваются, недавно показанные не повторяются, внутри одного теста повторов нет.

Интерфейс на русском и на турецком, переключается одной кнопкой. Объяснения к заданиям есть на обоих языках.

## Учебные материалы

Раздел материалов: 10 учебников, 88 юнитов с названиями, диапазонами страниц, списком грамматики и тем, с фильтром по уровням.

- Istanbul Yabancilar Icin Turkce A1, A2, B1, B2, C1 (Istanbul Universitesi Dil Merkezi)
- Yeni Hitit 1, 2, 3 (Ankara Universitesi TOMER)
- Yedi Iklim Turkce B1, B2 (Yunus Emre Enstitusu)

Каждая тема банка привязана к конкретным юнитам этих книг, поэтому после теста разбор ошибок показывает, какой юнит и какие страницы открыть.

Упражнения из учебников не копируются: это защищённый материал. Задания написаны специально для теста по темам и лексике юнитов, а ссылки на юниты и страницы даны, чтобы сдающий открыл свою книгу.

## Результат

Уровень CEFR, вердикт по уровню с порогом 70 процентов, таблица по секциям, полный список заданий, разбор каждой ошибки, темы на повтор, рекомендации по юнитам учебников, оценка активного словаря, разрыв до цели в учебных часах. Результат можно распечатать, сохранить в PDF или выложить картинкой в соцсети.

## Как устроено

Один файл index.html без сборки и без зависимостей, кроме jsPDF с CDN для выгрузки протокола. Прогресс, профиль и история попыток лежат в localStorage браузера и никуда не отправляются.
