# Alterna Seviye Sinavi

Экзамен на уровень турецкого языка в формате TOMER для русскоязычных. Одна страница, без бэкенда: всё считается в браузере, результаты хранятся локально у сдающего.

Сайт: https://timaxmetov.github.io/alterna-seviye-sinavi/

Телеграм канал проекта: https://t.me/alterna_turkish

## Что внутри

Шесть режимов: виртуальный экзамен TOMER на 47 заданий и 45 минут, адаптивный тест, экзамен по одной секции, тренажёр с мгновенной проверкой, работа над ошибками, тест словарного запаса.

Пять секций: грамматика, лексика и идиомы, чтение, аудирование, письмо и построение фраз.

Банк из 277 заданий A1 - C1. Каждое задание привязано к теме программы набора Istanbul Yabancilar Icin Turkce. Задания и порядок вариантов перемешиваются, недавно показанные не повторяются.

Результат: уровень CEFR, вердикт по уровню с порогом 70 процентов, таблица по секциям, полный список заданий, разбор каждой ошибки, темы на повтор, оценка активного словаря, разрыв до цели в учебных часах.

Профиль и цель: имя, целевой уровень, зачем нужен язык, срок и часы в неделю.

Личный кабинет: история попыток, динамика уровня, статистика по темам.

Выгрузка: PDF протокол, картинка результата для соцсетей, печать.

Два языка интерфейса: русский и турецкий, включая объяснения к заданиям.

Пауза и черновик: таймер останавливается, незаконченный экзамен продолжается с того же вопроса.

## Технически

Один файл index.html, без сборки. Внешняя зависимость только одна: jsPDF с CDN для протокола. Данные сдающего лежат в localStorage его браузера и никуда не отправляются.
